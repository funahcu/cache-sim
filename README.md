# Codes for cache-sim-funahcu.streamlit.app

## ネットワークトポロジの生成

4つのモデルから選びます
* BA Model  
  ノード数、リンク数が指定可能
* Scale-Free  
  ノード数、リンク数が指定可能
* Grid  
  行数、列数が指定可能
* WS  
  ノード数、近隣数、張り替え確率が指定可能

→ Draw Network ボタンでトポロジを生成します  
→ 同じ条件で別トポロジを生成したい場合は Re-generateボタンを押します  

## トポロジ生成後の画面での操作

* 起点ノード選択（Node 0 となっているドロップダウンリスト）  
  単一ノードを指定できる他、特殊な選択ができます
  - All (static)  
    すべてのノードを起点としたときの経路を計算しますが、現状のキャッシュ状態をそのまま使います
  - All (dynamic)  
    すべてのノードを起点としたときの経路を計算しますが、アクセスが進むごとにキャッシュの状態が更新されていきます
* 取得先選択（Orig となっているドロップダウンリスト）  
  以下から選択できます
  - Orig  
    Orig （コンテンツの供給元）のみを取得先（経路終点）とします
  - Cache or Orig  
    Origだけでなく、Cacheも取得先（経路終点）とします
  - Cache  
    Cacheのみを取得先（経路終点）とします
* All Orig ボタン  
  トポロジに表示されているノードすべてをOrig（コンテンツの供給元）ノードとします
* All None ボタン  
  トポロジに表示されているノードすべてのコンテンツをクリアし、どのノードもコンテンツを持っていない状態にします
* Src→None ボタン  
  いま起点となっているノードすべてをコンテンツ保持無し状態にします
* ノード状態の変更  
  ノードをダブルクリックすると以下の状態をローテートします  
  - Orig
  - Cache
  - None

## トポロジ図のみかた

* 起点ノード  
  星印（☆）で示されます
* コンテンツ供給元ノード（Orig）  
  赤いぬりつぶしで示されます
* キャッシュノード（Cache）  
  緑のぬりつぶしで示されます
* コンテンツを保持しないノード（None）  
  ぬりつぶし無しの丸で示されます
* 経路上のノード（Waypoint）  
  黄色の枠で示されます  
  指定された取得先が存在しない場合は何も表示されませんが、ノードのクリックにより設定されればただちに経路が描画されます  
  経路は最短経路のうちひとつが選ばれます

## All (dynamic) モードの操作

All (dynamic) を起点に選択すると、アクセスパターンを詳しく指定できるモードに入ります  
大きくわけて「テキスト貼付」タブと「エディタ」タブがあるので、いずれかを選択します  
（Dynamic optionsというタブに入っていて、これらは非表示と表示を切り替えられます）

### テキスト貼付モード

1行に1ノード番号でアクセス元のノードを指定していきます  
テキストなのでコピーペーストで貼り付けできます  
#から始まる行はコメントとして扱われます

→「このパターンを使う」ボタンを押して、入力行と同じ行数がステップとして表示されたらokです

### エディタモード

自動生成が可能なモードです  
生成されたパターンをテキスト修正できます

ドロップダウンリストから以下を選択して「生成／リセット」ボタンを押すと表組の中にアクセスパターンが生成されます
* デフォルト（0→n順, 1回）  
  0からノード数まで数字の順に1回ずつアクセスするパターンを生成します
* ランダム生成  
  現在のノードの中から重複を許してノード数分のアクセスをランダムに生成します
* 次数指定  
  指定した次数以下のノードをすべて選択します  
  次数範囲は現在のトポロジに実際に存在する次数に自動的に設定されます

### Dynamic options共通オプション

* 起点ノードにはCacheを作らない  
  このチェックを入れると起点ノードがコンテンツを取得してもCacheは作成されません
* 起点ノードは中継点でもCacheを作らない（上のオプションを含む）  
  このチェックを入れると中継点にキャッシュを作成するオプションにおいて起点に指定されたノードが中継してもキャッシュはしません（起点も含むので上のオプションは自動的にオンになります）
* キャッシュ作成確率  
  中継したノードがキャッシュを作成する確率として、0%から100%までスライドバーで設定できます
